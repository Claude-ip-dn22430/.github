<p>打开一个服务商官网，前三十秒你大概会看到三样东西：一堆形容词、一张价格表、一个客服按钮。真正能用来判断的信息，其实藏在几个不起眼的位置——页面里有没有写清 ASN 和出口类型、计费单位写到什么粒度、有没有自助查询入口。这篇按时间排：第一天看什么、第三天验什么、第二周看速度曲线的形状、第二个月判断要不要长期留。四个阶段，每段只做少量动作，但每一段都能推掉一批不合格的选项。</p>

<h2>一、看官网的顺序，比看哪家更重要</h2>
<p>先看什么后看什么，决定了你会不会被页面文案带走。合理的顺序是：先找事实性信息（出口类型、地区范围、计费粒度），再看服务承诺（响应时间、变更政策），最后才看价格。反过来先看价格，后面所有判断都会被「便宜」这个锚点污染。</p>
<p>事实性信息的特点是具体、可核对。比如「出口 ASN 为当地宽带运营商，可自助查询当前 IP」是事实；「原生家宽，稳定高速」是形容词。页面上形容词越多、事实越少，越需要自己动手验。</p>
<p>这一阶段不用做决定，只是筛选。把候选压到两三家，再进入后面的实测。</p>

<h2>二、第一天：只看三件事</h2>
<h3>有没有自助查询入口</h3>
<p>一个愿意让你查的服务商，通常会提供当前出口 IP 的查询页面或接口。有这个东西，意味着你随时能核对出口，不用每次都找客服。没有的话，说明它的线路状态对你不透明，后面所有排障都会变慢。</p>
<p>判断动作很简单：注册后找一圈，看能不能不通过人工就查到「当前线路的出口 IP、ASN、地区」。找不到，就记一笔。</p>
<h3>计费单位写到什么粒度</h3>
<p>「按量计费」这四个字背后可能是按 GB、按小时、按天、按月，差别很大。页面上如果只写「灵活计费」而给不出具体单位与阶梯，基本可以判断为需要人工谈。人工谈不是坏事，但要意识到这意味着价格不透明，比价会很困难。</p>
<h3>变更政策写没写</h3>
<p>出口变更、地区变更、退订、降配，这四件事的处理方式有没有写清楚。写清楚的，说明它遇到过这些问题并有流程；只写「以实际为准」的，意味着一切看当时。</p>

<h2>三、第三天：把「独享」验成数据</h2>
<h3>同时在线，逐个查出口</h3>
<p>「单账号独享独立出口」这句话只能靠实测确认。方法是让两个账号同时在线，各自查询出口 IP。IP 不同只是第一步，还要看 ASN 是否相同、地区是否相同。两个号 IP 不同但 ASN 完全一致、地区也一致，虽然不算串线，但关联度仍偏高。</p>
<p>更细的一步是看会话痕迹。登录后查看账号的设备列表，如果出现陌生终端，基本可以确定这条线不是独占。这一条比查 IP 更直接，因为它是平台侧给出的证据。</p>
<h3>速度忽快忽慢，三天能看出苗头</h3>
<p>共享线路的典型表现是高峰时段变慢。三天里至少覆盖一个工作日高峰（早十点到晚八点）和一个夜间时段，每个时段压 60 秒，记 P50 与 P95。如果高峰期的 P95 是低峰期的两倍以上，说明这条线在被人挤。</p>
<p>独享线路的曲线通常更平：高低峰之间的 P95 差异在 30% 以内算正常，超过 50% 就要怀疑是否真的独占。</p>

<h2>四、第二周：看曲线的形状，而不是单点速度</h2>
<h3>把延迟按小时画出来</h3>
<p>单次测速没有意义，曲线才有。用脚本每十分钟记一次延迟，连续跑一周，按小时聚合出 P50 和 P95。理想的曲线是平的，允许有小幅波动；不理想的曲线有明显的「峰谷」，且峰谷与办公时间高度吻合——这就是共享拥挤的典型形状。</p>
<p>还有一种形状是「周期性尖刺」，每隔固定时间出现一次延迟飙高。这通常不是拥挤，是运营商侧的重拨或链路维护，属于可预期行为，可以把关键任务避开那个时段。</p>
<h3>断线是否集中在固定时间</h3>
<p>一周里如果断线都发生在凌晨同一时段，属于运营商策略，可接受；如果白天随机出现且伴随延迟升高，说明线路质量不稳，该考虑更换。记录时把时间戳写清楚，别只写「断过几次」。</p>

<h2>五、第二个月：判断要不要长期留</h2>
<h3>四个可以量化的指标</h3>
<p>一是出口变更次数：一个月内变化不超过一次，说明稳定。二是地区漂移：一次都没有，说明锁定有效。三是非计划断线：三次以内可接受，超过就该谈。四是排障响应：报障后能否在半小时内给出结论，而不是让你自己排查。</p>
<p>四项里前两项决定账号侧的稳定性，后两项决定你的时间成本。四项都过关，这条线可以长期用；有两项不过，换的收益通常大于继续优化。</p>

<h3>长期合作前再问一句</h3>
<p>问：如果下个月出口必须变更，会提前多久通知、能不能指定新地区。这个问题的答案能看出对方是把你当长期客户还是当一次性订单。愿意给通知期和指定权的，通常内部有流程；答「到时候再说」的，你就要自己留好备用方案。</p>

<h2>常见问答</h2>
<h3>官网写得越详细就越可靠吗？</h3>
<p>答：不一定，但写不出细节的一定要小心。详细不等于真实，所以关键信息仍然要自己核。可以这样用：官网负责提供「该查什么」的线索，实测负责给结论，两者不互相替代。</p>
<h3>独享线路为什么也会偶尔变慢？</h3>
<p>答：独享指的是这条出口不与他人共用，不代表整条链路独占。上游汇聚、运营商互联、跨境出口拥塞都会影响速度，这些不在服务商的控制范围内。判断是否正常，看曲线形状而不是单点数值。</p>
<h3>一个月的观察期是不是太长？</h3>
<p>答：如果只是判断「能不能用」，三天就够；判断「要不要长期合作」，一个月比较稳，因为月度维度的变更和断线才有统计意义。中间可以并行使用候选方案，不必串行等待。</p>
<h3>发现不是真独享，能退吗？</h3>
<p>答：看约定。建议在采购前明确「出口类型与独占性与描述不符时可按比例退款或换线」，并保留第三天的实测记录作为证据。没有约定的，只能协商，主动权会小很多。</p>
